# YouTube Proxy

1. צור מאגר ציבורי (Public) ב-GitHub והעלה אליו את כל הקבצים שבתיקייה זו.
2. הרץ את `set-token.bat` ליצירת `COOKIE_KEY` ושמירת הטוקן ב-`extension/config.js`.
3. במאגר ה-GitHub הגדר Secret בשם `COOKIE_KEY` עם הערך שנוצר.
4. טען את התיקייה `extension/` בדפדפן דרך `chrome://extensions` במצב מפתח (Load unpacked).
